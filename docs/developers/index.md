# Developers

No public Main's World API endpoint is callable today. The current developer
material is reviewed release documentation: it helps people understand the
catalog and a possible future contract, but supplies no runtime access,
credentials, or activation.

## What is public now

- [Apps](/developers/apps) is the honest SPACE catalog. A listing is not an
  integration, grant, or activation.
- [API preview](/developers/api) records a non-callable Connectives contract and
  its reviewed snapshots.
- [Submit an app](/developers/submit-an-app) explains how to propose a public
  catalog listing through GitHub.

## The platform boundary

Main's World keeps identity, authentication, consent, native actions, credits,
wallet, Vault, and withdrawals inside the World App. A catalog entry or merged
submission never changes those boundaries.

If you have a partnership question, write to
