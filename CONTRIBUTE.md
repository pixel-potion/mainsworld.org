# Contributing to the Main's World knowledge base

Thank you for helping make this a source the whole world can trust.

The fastest way to help: on any page of [mainsworld.org](https://mainsworld.org),
click **Edit this page** at the bottom — it opens the GitHub editor for that file
and walks you through proposing a change (a pull request).

Prefer to work locally?

```bash
git clone https://github.com/pixel-potion/mainsworld.org
cd mainsworld.org
npm install
npm start
```

Please keep every contribution **accurate, plain-language, calm, and
public-appropriate** — no internal specs, security details, or unshipped features
described as if they were live. The full guidelines (and our house style) live in
[`docs/contribute.md`](docs/contribute.md), published at
[mainsworld.org/contribute](https://mainsworld.org/contribute).
