# Agent instructions (Codex, Claude Code, any other agent)

This is the public knowledge base for Main's World (Docusaurus → mainsworld.org,
CC BY 4.0). It is a curated public subset written from the app repo's internal
PRD: never publish secrets, the World App ID, auth or security internals,
internal specs, open questions, or unshipped economics stated as fact.

House style: plain language a non-technical reader can follow, expand every
term on first use, calm and hopeful, no emojis, and never describe something
that isn't live as though it were. Unshipped work is labelled and lives on the
Roadmap page.

`DESIGN.md` is the UI standards floor for every site we ship, this one
included: interfaces don't explain themselves, standard patterns before
invented ones, text fields never under 16px, legibility and touch rules. The
site's brand layer is `src/css/custom.css`.
